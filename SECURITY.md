# Security

For suspected vulnerabilities involving SSH trust, credentials, command construction, database writes, or diagnostic disclosure, contact **support@chenghengsheng.top** privately. Do not post a public reproduction containing secrets or server access details.

Include the affected source commit, macOS version, a minimal reproduction with fictional hosts, expected behavior, and actual behavior. Redact private keys, passwords, tokens, and identifying server data.

Maintenance focuses on the current main branch. No response-time or independent-security-audit guarantee is made.

Review SSH fingerprints against a trusted source. Use least-privilege server accounts and backups appropriate to the operations you approve. App confirmations and operation logs do not replace server-side access control or rollback planning.
